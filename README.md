## 🌐 Deployment to GitHub Pages

### Step 1: Create Repository
1. Go to [GitHub](https://github.com) and create a new repository
2. Name it: `Tawfeektoima.github.io`
3. Make it public
4. Do not initialize with README

### Step 2: Upload Files
```bash
# Navigate to your project folder
cd /path/to/your/portfolio

# Initialize git repository
git init

# Add all files
git add .

# Commit files
git commit -m "Initial commit - Portfolio website"

# Add remote repository
git remote add origin https://github.com/Tawfeektoima/Tawfeektoima.github.io.git

# Push to GitHub
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub
2. Click on **Settings**
3. Navigate to **Pages** (in the left sidebar)
4. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
5. Click **Save**

### Step 4: Access Your Website
Your website will be live at:
```
https://tawfeektoima.github.io
```

⏱️ It may take 2-5 minutes for the site to go live after the first deployment.

## 🎨 Customization

### Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --accent-color: #8b5cf6;
}
```

### Content
- Personal info: Edit the HTML in `index.html`
- Projects: Update the project cards in the Projects section
- Skills: Modify skill tags in the Skills section
- Experience: Update timeline items in Experience section
